# Real Photos Directory

Place your personal professional photos here:
- `photo-01.jpg` (Hero landscape / 21:9 or 16:9 recommended)
- `photo-02.jpg` (About portrait / candid workspace)
- `photo-03.jpg` (Moments / projects / lab / graduation)
- `photo-04.jpg` (Moments / campus / event)
- `photo-05.jpg` (Moments / tech setup)

### Recommendations:
- Format: JPG, PNG, WebP or AVIF
- Size: Max ~300 KB per photo for optimal loading speed
- When images are absent, the website automatically falls back to an elegant monogram frame with "VA" and "Photo to be uploaded" label. No broken images will ever be displayed.
